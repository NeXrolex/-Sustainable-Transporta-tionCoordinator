# Final Delivery – Campus Parking and Exit Carpool Coordination

This folder contains the materials for the **Final Delivery** of the project  
**Campus Parking and Exit Carpool Coordination**, developed for the course  
*Systems Analysis & Design* at Universidad Distrital Francisco José de Caldas. 

## Structure

### Final report.pdf
Final version of the project report.  
It integrates all phases of the work: empirical diagnosis, conceptual system design,  
stakeholder and risk analysis, implementation strategy, and simulation-based validation. 

### FinalDeliverySlides.pdf
Slide deck used during the final presentation.  
Summarizes the problem, the socio-technical solution, main data findings,  
architecture, simulation results, and conclusions. 

### Poster.jpeg
Visual poster of the project.  
Highlights the motivation, proposed system, key metrics, and main lessons learned  
from the workshops and simulations. 

### parking_automaton.py
Python script used to execute the simulation of the system.  
Implements the core logic to explore parking demand, overflow, carpool matching,  
cancellations, and behavioral dynamics under different scenarios. 

## Purpose

The **Final Delivery** gathers the finished academic products of the project and shows  
how the proposed socio-technical system evolved from initial analysis to a validated  
design, ready for a controlled pilot or future software implementation. 

## Project Context

This delivery builds on the previous stages:

- **Workshop 1:** empirical diagnosis of parking saturation and informal coordination.  
- **Workshop 2:** conceptual architecture and operational structure of the system.  
- **Workshop 3:** socio-technical refinement, stakeholder mapping, risk and quality framework, and implementation plan. 
- **Workshop 4:** simulation and validation of system behavior under baseline, optimization, and failure scenarios.
